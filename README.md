# NeuralSkills

**Practical knowledge, made reusable.**

NeuralSkills is a repository for reusable AI agent skills: task-specific instructions and practical know-how for carrying out defined work.

The focus is on the skills themselves. A skill should make clear what it is useful for, how to apply it, and where its limits lie. Supporting material belongs alongside a skill when it directly helps put that knowledge to work.

The aim is to make useful methods easier to share, adapt, and improve, so the knowledge developed for one task can become a starting point for the next.

Contributions should add a clearly defined skill or improve an existing one. The standard is practical usefulness: clear instructions, relevant examples, and capability claims grounded in observed results.

> **What we learn to do well should help others do it better.**
