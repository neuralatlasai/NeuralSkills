# MAINTAIN — Diagnosis, remediation and feedback

Turn qualified operational evidence into supported diagnosis, authorized action or explicit ownership transfer. Keep recovery, causal proof and closure separate.

## Route and load

Use for service health, incident follow-up, vulnerability/dependency triage, maintenance and retirement. Route changed needs to PLAN, contracts to DESIGN, patches to BUILD, assessment to TEST and promotion to DEPLOY; continue when already authorized.

For stage work, read [governance](../shared/governance.md), [artifact contracts](../shared/artifact-contracts.md) and the [stage procedure](references/procedure.md). A routing-only answer needs no deeper resources. Collect only dependent inputs using [project context](../shared/project-context.md). Read [standards](../shared/standards-register.md) when selecting or discussing a reference baseline and [platform adapters](../shared/platform-adapters.md) when relying on actual host behavior.

## Workflow

Identify service/release, observations, access and prior unknown actions; qualify data; compare symptoms/hypotheses under actual objectives and severity policy; select proposal, authorized runbook action or transfer; recheck authority/recovery/controls; observe outcomes and regressions; preserve unresolved risks and operating ownership.

Use [maintenance-record.md](../shared/templates/maintenance-record.md) or a documented equivalent preserving IDs, revisions, evidence and status. A clear authorized task, issue and existing repository contracts can suffice for a compatible small change. Formal review is conditional on actual governing authority. Continue all already authorized stages; a handoff alone does not complete the user's broader task.

## Boundaries and exit

An alert grants no production authority. Distinguish objectives, calibrated statistical limits and alert thresholds. Missing objectives allow observations but prevent invented health pass/fail; missing severity policy prevents invented labels. Communicate only as authorized. Close with supported resolution or explicit accepted unresolved ownership/risk; transfer is not resolution. ISO 14764 does not mandate operational backup/recovery controls.

Act only within existing task/tool/data scope. Report authored, executed, verified and approved states separately. Missing evidence blocks only its dependent claim/action; never fabricate a result, approval or standard clause. Validate current records using ART-1 and exercise relevant [evaluation cases](../evaluations/cases.md).
