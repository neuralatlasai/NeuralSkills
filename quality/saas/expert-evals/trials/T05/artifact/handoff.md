# T05 handoff

The settings editor is repaired in `app.ts`, `index.html`, and `styles.css`. `mount(root) => {dispose()}`, all supplied IDs, labels, demo loading, and output semantics are preserved. This is a native TypeScript/CSS synthetic widget; no backend, framework, package, routing, global modal manager, or animation layer was added.

## Objective and evidence

Route: improve-existing small component. The supplied UI-U2 task is the authority for U2-R1 through U2-R4. Audience/task: pointer and keyboard users edit a workspace name, save once, or discard. Acceptance was the supplied semantic modality, lifecycle, focus, viewport, and mechanism requirements. Reference input was the copied local fixture and selected frozen 1.1.0 skill only; no other heldouts, checkers, graders, or previous solutions were inspected.

Original symptom reproduced in real Chrome: at 320x480 the DIV panel was 600px wide, extended to x641/y1112.69, and sat at x41/y224.88 inside a 280x200 clipped transformed card. Escape hid it but left `body.style.overflow` as `hidden`. See `baseline.json` and the executed `node baseline.mjs` historical probe. The actual containing-block geometry plus inspected transform/overflow rules distinguish ancestor clipping from a z-index-only issue. A z-index increase cannot escape that clipping or implement focus containment. Original JS had no semantic modality/focus owner and only removed the opener listener during disposal.

A plausible alternative is a custom body-level overlay using reparenting plus explicit inertness, focus trap, return-focus, Escape, and lifecycle cleanup. It becomes appropriate when an explicitly required legacy browser cannot support native dialog or the product needs a specialized non-modal interaction. For this fixture it adds several failure-prone owners that the browser already supplies. A portal/focus library is unnecessary and prohibited; a global modal manager has no second modal consumer here. Raising z-index alone is rejected because the original ancestor establishes the clipping/containing block.

## Verification and limits

Run from this artifact directory: `node verify.mjs`. It starts the unchanged shared helper on an ephemeral loopback port, launches the installed Chrome in headless mode, runs real pointer/keyboard/browser checks, writes raw JSON/screenshots, and closes browser/server. Final run exited 0 with all recorded checks PASS and no page errors. All behavior is implemented rather than simulated; diagnostic outside-click counting exists only in the test page. No network service/data behavior was claimed.

Visual review confirmed readable title and label at the top, wrapped policy text, visible blue keyboard focus, bounded panel edges, and reachable actions at the bottom. The original 600px policy spacer is retained as supplied content stress, so the settings card remains deliberately long. No full WCAG conformance, AT/screen-reader pairing, contrast scanner, browser zoom, Safari/Firefox/mobile keyboard, static TypeScript checker, or field performance measurement was performed. Those are UNVERIFIED coverage, separate from the executed task checks. The shared server strips TS but does not statically typecheck it. No performance optimization was requested.

## Failures and provenance

The first `node baseline.mjs` attempt failed before browser startup with Node `ERR_UNSUPPORTED_ESM_URL_SCHEME`: a Windows absolute path was used as an ESM import. Changing it to the file:/// URL for the same installed Playwright module fixed the harness. That failure is retained in `failures.txt`. The next baseline probe passed and retained the original defect evidence. Both implementation browser runs passed. Initial screenshots showed that focus scrolling could hide the heading; opening now resets dialog scrollTop to zero and uses preventScroll focus, followed by a successful rerun and visual inspection.

Budget accounting is in `trial-budget.json`. No child agents, package installations, downloads, external mutations, or shared infrastructure edits occurred. The first tool captured UTC via the clock tool; the requested PowerShell ISO timestamp was captured in the following read batch, a procedural deviation retained here. Model token and monetary cost measurements are unavailable (null).
