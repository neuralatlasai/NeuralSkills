# Orbit reproduction

Requirements: Node 24 or another static HTTP server; no dependencies or installation.

From this artifact directory run `node server.mjs`, then open http://127.0.0.1:4182. Stop with Ctrl+C.

The supplied 1280×900 PNG governs desktop appearance. Arial/system fallback is local. At 700px the navigation wraps, artwork and cards stack. Native dialog supports Escape, focus containment and restoration; workspace creation is a local message only. Navigation uses document section anchors. All projects links to the projects section because no additional project screen is supplied.

Verification scripts and raw screenshots are stored in the sibling evidence directory. No backend, remote font, image asset or network service is used.
