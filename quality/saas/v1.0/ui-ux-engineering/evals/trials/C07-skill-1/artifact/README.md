Run `node build.cjs`, then `node serve.cjs`, and open http://127.0.0.1:4317. Requires Node 24 and the TypeScript API path recorded in build.cjs; change that path for another machine. No packages or network downloads required. A precompiled app.js is also supplied.

This single-page local demonstration keeps data only in memory. Reload resets it. Confirmation does not send a reservation or email. copy.json is an unchanged copy of the supplied bilingual content. Native radio choices allow long German strings to wrap. No animations, assets or external fonts.
