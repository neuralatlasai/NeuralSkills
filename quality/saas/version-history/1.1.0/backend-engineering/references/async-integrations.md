## Recover logical effects

Local transaction: persist scoped operation identity, parameter binding and effect together where supported. Commit succeeds but response disappears: reconcile the same identity on authoritative state with current authorization/deletion/projection policy. A stale replica's absence proves no absence of commit. Retention must cover actual replay horizons.

External effect: outbox coordinates local state/publication intent, not provider completion. Persist intent before calling; use provider idempotency/status reconciliation only if supported. Provider applies effect then response disappears: a new key may duplicate it. Restart/reconcile the same operation or retain explicit unknown state and authorized resolution owner. Compensation is another fallible operation with its own authority, identity, retries and recovery, not guaranteed rollback. Transport timeout/cancellation does not prove failure.

Ownership: a lease cannot stop a paused worker. If fencing is required, name the participant rejecting an older monotonic epoch at effect commit. Schedule A pauses -> lease expires -> B commits -> A resumes. Storage/provider must reject A; a token only logged has no effect. If a participant cannot fence/deduplicate/reconcile, expose overlap risk and choose a workable contract.

Neither synchronous RPC nor messaging alone supplies durable ownership/isolation or global exactly-once semantics. Apply the service-boundary decision in [data](data.md) when proposing extraction.

On failure, contain amplification, quarantine poison/uncertain work with durable context, and resume through the declared replay/repair owner. Existing source and adapter limits: [register](sources.md), [adapters](adapters.md).
