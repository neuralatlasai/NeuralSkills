# Lilac billing starter

A deliberately small existing React + TypeScript + Vite page. The initial artifact does not contain the requested payment-schedule feature. Keep its brand tokens and existing content.

- Install: npm install
- Run: npm run dev -- --host 127.0.0.1
- Static check: npm run typecheck
- Production build: npm run build

Dependencies are pinned for reproducibility. This fixture is not the trial implementation; copy it into trial/artifact before editing. Existing Overview/Settings links are nonfunctional placeholders outside this task's scope.
